# Amendment — 2026-10-18

Applies the decisions of [the reconciliation map](MAP_URL). Where it conflicts with the refinement below, this amendment wins.

- **Selection (ADR 0031).** No viable Unattended Selection exists. Until #22 qualifies an alternative, the Operator reads weights and computes the weighted pick from the contract's combined randomness. The contract still enforces the randomness threshold, the Winning Commitment, and the private claim. The Operator learns the weights and balances it uses and is trusted to select fairly. Public state is unchanged. This supersedes decision 11 of `docs/midnight-stack-review.md`.
- **Privacy (ADR 0005).** Two Preprod losses are accepted and disclosed before contribution: a withdrawal publicly retires its note by leaf index or nullifier, linking note lineage; and the Operator sees the weights and balances it selects with. ADR 0005 otherwise holds.
- **Chain data.** Blockfrost serves Preprod indexer and RPC. A read-only Chain Data Proxy on Render holds the public token and serves only pre-connect and public contract-state reads. After connect, reads use the wallet's `getConfiguration()` endpoints, falling back to the proxy. The proxy caches about one block, merges identical in-flight requests, allowlists operations, and rate-limits each IP to about 2 req/s. On 429 or quota exhaustion it serves stale data with its age or a typed "chain data unavailable" error. A separate operator account serves the Sponsor, Automation Service, and Operator CLI. Free tier: 50,000 req/day, 10 req/s per IP with a 500 burst; Better Stack alerts at 80%. Known limitation: proxy and Sponsor may share a Render egress IP (unverified). Finality waits use `watchForTxData`, then serial probes with 2→4→8s backoff capped at 10s, within 120s.
- **DUST.** For every operator wallet (Sponsor, deployer, randomness, evidence), the runbook checks: fund tNIGHT, `registerNightUtxosForDustGeneration`, wait for visible DUST. `faucetTiming` measures registration to DUST. Fallback onboarding tells participants to register their own tNIGHT.
- **Profile.** Node 1.0.400, proof server 8.1.3, indexer 4.3.302 (unverified), wallet-sdk 1.2.0; the rest per `midnight/version-profile.json`. Node 1.0.400 rejects some calls 8.1.2 accepted.
- **#22 acceptance.** Re-run on proof server 8.1.3; 8.1.0 evidence is not accepted. Record proving time, key size, and tx size against: tx ≤ 786,432 bytes, k ≤ 25, verifier key ≤ 50,000 bytes. Documented block limits differ from Preprod genesis and are cited as unverified.
