## Acceptance criteria

- [ ] Preserve the selected C visual direction: chronology beside private position, position first
  on narrow layouts, clear Preprod/test-value and public-timing disclosures. Use the accepted copy
  from #71: hero "Save privately. Draw in the open.", eyebrow "Private savings, public draws",
  trust chip "Operator-selected draws (Preprod)", cohort copy "five commitments are not five
  people", and the "What Preprod does not keep private" section.
- [ ] Connect/disconnect with explicit authorization, display the qualified profile, and explain
  actual wallet, prover and deployment blockers. No private import/unlock or financial actions on
  unsupported environments; no hosted-prover fallback.
- [ ] Use build-time environment-locked configuration with a sanitized snapshot and no runtime
  switch. Reject wrong contracts/networks, fail closed for Mainnet transactions and exclude test
  wallet bridges and retired EVM dependencies from the active release. Pre-connect public reads use
  the read-only Chain Data Proxy; after connect, reads use the wallet's `getConfiguration()`
  endpoints with proxy fallback. No Blockfrost token reaches the bundle. Show stale data with its
  age, or the typed "chain data unavailable" error.
- [ ] Show public journal availability honestly; fixtures are explicitly development-only and never
  presented as real draws. Verify readiness, disconnect and unsupported-device browser cases through
  the application boundary.
